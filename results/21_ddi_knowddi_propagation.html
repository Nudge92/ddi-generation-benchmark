21 · 5세대(KnowDDI 2024) 핵심 아이디어 축소재현 — '유사도 전파'가 신약을 뚫나

구조로 이웃을 찾아 그 이웃의 '관계'를 전파. ★분류기 고정(XGBoost)·유일 변수=전파 방식(V1 없음/V2 구조/V3 관계). 11·14·15·16과 동일 데이터·분할·지표 · env admet · 1251s

한 줄 결론: ★전파도 cold-cold 벽을 못 뚫음 — V3 0.218 vs V1 0.252(Δ-0.034) = 표현/데이터 병목 재확인. cold-cold macro-F1: V1 0.252 · V2 struct_prop 0.272 · V3 relation_prop 0.218 (★V2가 수치상 최고이나 warm 0.59≪V1 0.78=표현 착시·깨끗한 전파 이득 아님 — ⑤).
★정직 프레이밍: 이는 KnowDDI 원본 재현이 아니라(Hetionet 등 외부 지식그래프 안 씀) 그 정수인 '유사도 전파'만 떼어 3버전 비교한 축소 재현이다. ★V1은 11 baseline과 bit-동일 재현(seed0 cc 0.2385 vs 앵커 0.2385) = 저울이 같음을 확인.
★누수 청정(아래 ③ 수치): 이웃풀=train만·자기 제외·rel은 학습쌍만 → cold 테스트 특징에 test 라벨·test-test 유사도 0 유입(전부 0, 5 seed). ★warm은 누수 맥락(참고만·V3 warm은 약물정체 암기로 부풀 수 있음). ★학습 정상(mlogloss 감소·NaN 0).

① 방법 (V1 없음 / V2 구조 전파 / V3 관계 전파)

세 버전 모두 per-drug 표현 → 쌍 특징 = feat[lo]+feat[hi](sum 융합·11과 동일)·분류기 fit_mc(XGBoost multi:softprob·XGB_MC 그대로) 고정. 유일 변수 = 전파 방식.
· V1 struct_only=자기 Morgan(전파 없음). ★희소 pair_feature 경로 = 11 baseline과 bit-동일(재현 앵커).
· V2 struct_prop=prop_fp[d]=구조 닮은 train 이웃 top-20의 Morgan을 Tanimoto 가중평균 → ★PCA 축소(train-fit·분산90%·P≈61·14/15와 동일 정론, 밀집 2048은 XGBoost 86-class서 비현실적 느림).
· V3 relation_prop=prop_rel[d]=같은 이웃들의 관계 프로필 rel을 가중평균(86차원). rel[g]=g가 참여한 그 regime의 학습 쌍(cold→tt·warm→wtr) 86종 유형 분포(정규화). ★이게 KnowDDI 정수(이웃의 '관계'를 빌려옴).
· 이웃 후보 = ★train 약물만(M2 열을 train_rows로 슬라이스)·자기 제외·가중치=Tanimoto/Σ. ★1세대 Vilar(13)는 직접 상호작용 경로가 필요해 cold-cold서 ROC 0.500 붕괴 — V3는 이웃의 관계 분포를 빌리므로 cold-cold서도 작동 가능(이 실험의 가설).

② 학습곡선 (전파 버전이 제대로 학습되나)

세 버전 모두 val mlogloss가 감소 → 학습 정상(NaN·발산 없음). 곡선은 cold TT 모델(seed0)의 내부 90/10 val 기준(시각화용·scored 모델은 전체 tt fit).

전부 0 = ★cold 테스트 특징에 (1) test 약물이 이웃 소스로 들어오거나 (2) test-test 유사도가 섞이거나 (3) test 쌍 라벨이 rel로 새는 경로 없음. rel은 학습쌍(tt/wtr)에서만 만들어 cold 테스트 쌍(ts/ss는 tt에 없음)의 라벨이 어떤 rel에도 안 들어감.
★남는 잔여(정직): 학습쌍 중 파트너가 구조 이웃인 경우 그 쌍의 특징에 자기 라벨이 희석되어(≈w_partner/Σw × 1/deg) 들어감 — 그러나 이는 학습쪽뿐이고 cold 테스트엔 없어, 있다면 cold-cold를 오히려 낮추는 방향(train/test 특징 분포 불일치). 따라서 V3 이득은 이 잔여로 설명되지 않음.

⑦ ★한계·정직 메모

· ★KnowDDI 원본 아님: Hetionet 등 외부 지식그래프·GNN 링크예측 헤드 안 씀 = '유사도 전파' 아이디어만 축소. 원본은 더 풍부한 KG로 더 나을 수 있음.
· warm 누수 맥락: 같은 약물 train·test 양쪽 → V3 rel이 약물 정체 노출로 warm 부풀 수 있음(참고만·결론은 cold 기반).
· top-K=20·정규화 분포·sum 융합은 선택값(민감도 미탐색) · V3 rel 정규화는 promiscuity(상호작용 수) 크기를 제거하고 '유형 패턴'만 남김.
· ★V2는 PCA 축소(분산90%·P≈61·train-fit·14/15 정론): 밀집 2048 borrowed 지문이 XGBoost 86-class서 비현실적으로 느려 불가피 — 분산 90% 보존이나 V1(희소 원지문)과 표현형이 달라짐(V1=희소·off-bit 결측 / V2·V3=밀집 전파벡터). 표현 축이 섞이나 변수는 여전히 '전파 유무·종류'.
· 비교는 파이프라인 전체(표현만 바꾸고 분류기 고정) — 순수 전파 효과 분리는 됐으나 다른 분류기(DNN 등)에선 다를 수 있음 · 이진(02~09)과 비교 불가 · seed 5개(통계력 제한).
